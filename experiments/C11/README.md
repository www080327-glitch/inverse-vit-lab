## 预注册和资源

Issue #9。两个 seed：11、29；单个 Node 训练进程，Linux CPU affinity 限制为最多 2 核；不启动工作线程、不下载模型或数据、不调用付费 API。总实验进程截止 1750 秒，外层 timeout 1770 秒；完整云端 job 最多 30 分钟。程序为 CPU 标量实现，不使用 GPU。

四个方案共享同一 seed 的数据、初始模型、预训练快照与新任务采样序列。旧保持方案另共享保持采样序列。固定 1200 次预训练更新、800 次新任务更新、最多 200 次保持更新；固定最终快照，不根据验证结果挑选。预训练未达到 >95% 验证 exact 则实验报错，不调参后隐藏失败。训练 2048、验证 1024，独立 seed 生成；不保存原始样本集、模型权重或优化器状态。

每个 seed 只预训练一次；两种关系和四个方案从相同快照分叉。teacher 为冻结深拷贝，每组运行后检查完整参数哈希。没有与学生共同更新。

## 任务与容量约束

输入是 8 个带符号连续标量，可视作 4 个二值 token 的强度与 4 个独立干扰特征，分别独立抽样。旧任务输出前 4 个标量的正负号，即固定长度离散序列；监督 CE 对 4 个 Bernoulli token 取均值。报告 token accuracy 和整序列 exact，并额外报告“旧教师原本整序列答对的样本里仍然答对的比例”。

共享网络：8→4 的可训练仿射瓶颈，两个独立可训练头：4→4 Bernoulli logits 和 4→16 连续输出。总共 136 个参数，远低于 100 万。所有共享层均可训练，没有 LoRA 或选择性冻结实验。任务头在没有对应损失时无梯度，不更新 Adam 状态；共享层承受所有任务更新。

新任务是预定义 16×4 符号基生成的连续场，MSE 对 16 个坐标取均值：
- compatible：重建旧任务也需要的前 4 个标量；
- conflict：重建后 4 个独立干扰标量。

两种目标分布规模相同，只改变所需输入子空间。共享线性瓶颈的秩最多为 4。对 conflict，若想对所有输入精确重建 4 个独立干扰量，4 维表示将被其占满，无法同时完美保存 4 个独立旧信号；这是**刻意构造的容量冲突**。真实大模型有冗余维度、非线性、任务标识和更复杂数据，此处不模拟它们。compatible 是相对兼容，也不保证旧 logits 在参数旋转与缩放后完全不变。

这不是自然语言推理任务，不模拟自回归生成，连续场也不代表真实视觉质量。

## 四个方案

|方案|新任务|真实旧标签 CE|冻结教师 KL|
|---|---|---|---|
|A|800 更新|无|无|
|B|800 更新|200 更新|无|
|C|800 更新|无|200 更新|
|D|800 更新|200 次同批|200 次同批|

每四次新更新之后，B/C/D 各做一次保持更新。D 在同一次保持更新将 CE + KL 相加，不是 400 次额外更新。系数均为 1；D 保持项更强，**不是保持梯度规模匹配的因果对比**。A 固定新任务暴露，因此只有 800 次优化器更新，其他为 1000；不能声称四组总优化步数或总计算量相同。这个取舍将计数显式记录；若要等计算预算对照应另开实验。

输出分布保持为每个旧 Bernoulli 分布的 KL(teacher || student)，温度 2，并乘 T²。C 使用旧输入但不读取旧标签。B 的 CE 直接使用真实标签。教师的错误会被 C 保留，C 并非真实标签替代品。教师前向时间单列，已包含在保持总耗时；诊断所需教师前向计入诊断成本。

## 如何读梯度

每 50 次新更新以及最终快照，用固定训练集 probe（64 个样本）测：
- 新 MSE、旧 CE、教师 KL 的原始数值；
- 共享 W/b 梯度 L2 范数；
- new↔CE、new↔KL、new↔CE+KL 余弦；
- 当前方案实际保持项的共享梯度范数。

probe 不取验证集。诊断不执行优化，也不改学生、教师或 Adam 状态。中间诊断发生在新更新后、该组保持更新前；最终诊断发生在全部更新后。训练时实际新/保持梯度范数累加另记录，不能拿固定 probe 范数代替实际训练贡献。

余弦反映当前局部一阶关系，零梯度返回 null；不是长期能力、优化轨迹或安全性的判定器。即使负余弦也需看真正训练后的保留率和新任务误差。范数和占比不考虑方向抵消，也不是 Adam 更新贡献归因。

## 为什么 20% 更新不是 20% Token、计算或梯度

保持 batch=16，新任务 batch=32。200/1000=20% 保持更新，但旧样本为 3200/28800=11.11%。旧答案每样本 4 个离散位置，新答案每样本 16 个连续坐标，旧位置数量占 12800/(12800+409600)=3.03%。连续坐标不是 LLM token，真实训练必须分别记录 token、图像、patch、latent 维度与有效 loss mask，不能混称。若只数两类输入相同的 8 个标量位置，则旧输入位置占比仍为 11.11%。

D 同一次旧前向服务两种损失，标签与教师目标计数不能相加当作独立样本。C 旧标签计数为 0。实际计算量看计时；这里只记录 wall time，不假称精确 FLOP。梯度比例看 results.csv，参数更新还受 Adam 状态、方向和时序影响。

## 诊断函数接入

gradient_probe.py 提供显式参数名、采样间隔和元素上限；默认每 100 步记录，最多 100000 个选定参数元素。不开启时无开销，不自动注册、不保存完整梯度文件。对每任务使用 autograd.grad，临时只保留选定层的梯度，返回标量后释放；不写 .grad、不执行 optimizer.step。

推荐先在几个共享层稀疏测量，例如每 100–500 步，同一参数状态下使用独立任务微批。任务 loss 必须未被 AMP GradScaler 放大，并记录各自 reduction、有效 mask、系数；诊断前向应隔离 RNG，避免扰动训练采样或 dropout。autograd.grad 仍需遍历反向图，选层只减少返回和临时存储的梯度，不保证反向计算按参数量等比减少。

每测一个任务通常需要额外前向与一次反向，并可能保留图；两任务每 100 步测一次，若每个任务微批成本相当，额外训练计算量量级约 2/100，具体以计时和显存峰值为准。含教师时还须计额外教师前向。函数没有宣称经过真实 Qwen/AMP/DDP/FSDP 验证；分布式统计默认 rank-local，不能未经聚合解释为全局余弦。训练与推理仍应直接评估固定指令成功率。

## 复现

Node 20 或更新版本；不需要 npm install：
~~~sh
node experiments/C11/runner.mjs experiments/C11/results
python3 -m py_compile experiments/C11/gradient_probe.py
python3 experiments/C11/package.py
~~~

云端 workflow additionally 限制 affinity 与 timeout。runner.mjs 自带新 MSE/CE/KL 手写梯度的有限差分验证、self-KL 零值测试、诊断不变性与教师冻结检查。PyTorch 函数仅做语法检查，当前无 PyTorch 运行验证，明确属于可移植候选工具。

ZIP 包含 C11 源码、结果、交接、校验和与失败例，不含自身、数据集、模型/优化器权重。与仓库现有训练文件隔离，不运行或修改对齐任务。
