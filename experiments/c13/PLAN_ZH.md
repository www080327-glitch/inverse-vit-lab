# C13 预注册与使用说明

目标：研究用编码器权重构造解码器初始化是否值得，而非把转置称为逆。

## 固定设计

- 纯 NumPy，float64，CPU，BLAS/OMP 上限 2 线程；无模型和数据下载。
- 16×16 自造灰度图，四种主体（旋转矩形、椭圆、细线、三角形）+独立细附件；位置、大小、角度、前背景强度随机。固定训练 768、独立验证 192；数据 seed 1300/1301。两实验 seed 为 13/29，数据相同。
- 编码器：256→64 tanh→64 tanh→24 linear。先训练500步，batch64，Adam(lr=.002, β=.9/.999, ε=1e−8)，目标为重建MSE+0.1×四分类CE；随后冻结编码器并校验哈希。编码器辅助解码器只用于预训练，不传给正式解码器。
- 正式解码器：24→64 tanh→64 tanh→256 linear，参数量和结构三组完全相同。
- A：独立随机 Xavier normal 权重、零偏置。
- B：E3ᵀ→D1，E2ᵀ→D2，E1ᵀ→D3；行向量约定，偏置 −bE@WD。偏置处理是线性仿射近似，并不穿过 tanh 构成精确逆。
- C：D1=pinv(E3)，D3=pinv(E1)，rcond=.001；两端偏置同上，中间 D2 保留 A 的初始化。仅比较这套端点初始化，不把结果解释成“任意层逐个求逆”。
- 三组从同一随机解码器快照复制，只有明示映射参数变化。每个 seed 使用完全相同的600步 batch索引和新建Adam状态；每组38400样本呈现。学习率不按组调优，运行顺序 A/B/C 固定。
- 记录 step0、1、10、每25步，固定第600步为终点；不根据验证集选择checkpoint或调参。初始误差只作一个指标。最终与全曲线均保留。
- 图像 MSE 与差分边缘 MSE：不裁剪预测，在原始 [0,1] 尺度计算；训练内部表示映射到 [−1,1]。没有只评价前景，背景可能降低整体 MSE。图谱仅显示裁剪。
- 收敛速度指标：固定验证MSE≤.02的首次已记录步数；未达到为null，不插值；另计算验证MSE对训练步数的梯形AUC/600。秒数受运行顺序/CPU噪声影响，仅辅助，不作为因果速度结论。
- 总训练预算1100秒（编码器与全部解码器累计），整个作业20分钟。无GPU、无付费API。预算超时按失败报告，不能补写未完成结果。
- 两seed是机制探索，不足以给出显著性或广泛架构结论。600步未必达到渐近最优。

## 参数映射（NumPy 行向量记号）

| 解码器参数 | 形状 | A | B | C |
|---|---|---|---|---|
| D1.W / W0 | 24×64 | paired random | E3.Wᵀ | pinv(E3.W) |
| D1.b / b0 | 64 | 0 | −E3.b @ D1.W | −E3.b @ D1.W |
| D2.W / W1 | 64×64 | paired random | E2.Wᵀ | 与A同一随机权重 |
| D2.b / b1 | 64 | 0 | −E2.b @ D2.W | 与A同一零偏置 |
| D3.W / W2 | 64×256 | paired random | E1.Wᵀ | pinv(E1.W) |
| D3.b / b2 | 256 | 0 | −E1.b @ D3.W | −E1.b @ D3.W |
| 两个tanh | 无参数 | 同结构 | 同结构；非arctanh | 同结构；非arctanh |
| 预训练辅助解码器、分类头 | 不进入正式解码器 | 不复制 | 不复制 | 不复制 |
| Q/K/V、LayerNorm | 本训练网络不存在 | 不适用 | 不匹配、不构造 | 不匹配、不构造 |

本例所有线性形状都兼容。C 的中间层有意独立初始化；不存在未记录的随机补层。完整逐参数映射在 PARAMETER_MAPPING.json 和 RESULT.json。

## 重跑

安装 Python3.12 与 requirements.txt 中的唯一依赖 NumPy2.2.6，在此目录运行：

    python experiment.py
    python make_report.py
    python package_delivery.py

只生成当前目录的实验产物，不搜索其他目录。源码的数学断言、有限差分梯度检验、参数量、数据划分与冻结哈希检查随实验执行。无必要下载现有仓库的模型或数据。生成数据由种子复现，不提交原始数组、权重或优化器状态。

GitHub一次性工作流只匹配本实验分支上的源码变动；结果提交不会触发后续训练。整个实验不会在用户Mac/DCU上执行，也不修改主分支或正在运行的训练。
