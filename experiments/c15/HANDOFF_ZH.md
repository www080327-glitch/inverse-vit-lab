# C15 连续输出头交接

本轮只比较已知合成向量分布，不代表图像画质，也没有验证 Qwen 视觉特征或自回归自由生成。
训练与测试为独立随机样本；四个离散条件在训练中各出现 2048 个目标。测试分布在训练前固定。
全部 24 次训练均采用最后一步，未用测试指标选 checkpoint；所有 seed、条件、失败和曲线均保留。

能量距离使用独立测试样本与生成样本的无偏 U 统计量，按 sqrt(d) 归一化，允许有限样本负数。每条件各 512 个样本，距离矩阵最大 128×128。真分布对独立真分布的有限样本参考在 oracle_baselines.json。各维度不可直接视为相同难度；选择规则对三种维度等权。

覆盖：按真实分量后验归类，且进入该分量 99% Mahalanobis 椭球的样本占总数至少 1%。宽高斯可能命中每个模式但产生很多无效点，因此同时报告有效比例、比例 TV、分量内协方差和分位数。模式重叠时，后验分配比例不完全等于潜在混合权重，二者与测试分配基线均保留。

MSE 输出重复的条件均值；它的失败是分布建模能力限制，不是重建任务不能使用平方误差。对角 GMM 可以用额外分量近似相关性，但本轮分量数固定为真实模式数；全协方差 GMM 的真分布就在模型族内，是有利的相关性对照。
EAR 的连续 MLP 可在模式之间产生连接样本；能量评分的严格适当性不保证有限网络、有限训练找到全局最优。

## 唯一下一轮候选

按预先固定的分布指标规则，本轮只推荐 **diag** 进入真实冻结视觉特征的小规模实验。这是一项待验证的实验候选，不是一般性优劣结论。

仍缺：真实特征与更高维度、非高斯分布、更多 seed、等时间计算对照、长序列自由生成、固定镜像解码器下的图像与小目标细节评估。下一轮应冻结编码器与解码器、保留真实多目标条件、统一生成预算，分别评估特征分布和解码图像。

## 规模与计算

累计训练 95.8 秒；训练线程 2，CPU affinity 2。每模型约 12000 参数，宽度根据实际输出维数调整；固定 one-hot 条件编码，无额外可训练主干。规模相近但结构和计算并不相同，因此不能宣称普遍更强。
每模型同样 1800 步、batch 128；EAR 每目标生成两份样本，MLP 前向计算约两倍；全协方差还需三角求解。逐模型真实秒数、参数、宽度、前向 dense MAC 估计和训练目标样本次数在 runs.json；MAC 不含反向、激活、优化器及求解器。

## 文件与复现

从本目录运行 python run.py；依赖 requirements.txt。既有训练预算文件会阻止静默重跑，要复现请使用新的 checkout 或明确保留旧证据后另建输出目录。统一接口 Head.sample(condition, n, generator) 返回 [B,n,d]，scalar condition 保留 B=1。EAR/MSE 的 NLL 为 null；MSE 是点质量，EAR 是隐式采样分布，均不伪造 Lebesgue 密度。
结果目录含逐 seed/条件指标、每次 loss/梯度记录、全部散点与全部边际图。图示范围固定，指标使用未截断样本。
不提交模型权重、优化器或原始数据；通过固定种子和分布参数重现。参见 SOURCES.md 的公式与实现核对、平方距离反例。
MANIFEST.json 校验包内文件；C15_DELIVERY.zip 为完整交付包。
