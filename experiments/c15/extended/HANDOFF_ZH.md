# C15 连续输出头：交接与中文结论

本轮唯一建议进入下一轮的是 **小型全协方差 GMM（full）**。选择依据是训练前固定的、三种维度等权的独立测试能量距离；它只是下一轮实验候选，不表示已满足相关结构、局部细节或真实图像生成要求。两个 seed 也不足以证明普遍优越或统计显著。

## 已执行范围与预算

全部实验与交付处理在标准公开仓库 GitHub Actions Linux CPU runner 执行；未读取本机项目、模型或其他会话文件，未在本机训练，也未访问 DCU，没有下载图像数据或模型权重。训练均设置 2 个 CPU 的 affinity、torch 2 线程及 interop 1。
初始阶段 1800 步 ×24 次；看到相关结构失真和模式间填充后，将所有方法统一重训至固定 9000 步 ×24 次。累计实际训练 **542.4 秒**（首轮 95.8，延长轮 446.6），低于 1800 秒。首轮全部输出、源码与失败现象均保留；没有挑最好 seed、没有按测试结果挑 checkpoint，也没有继续调预算。

每个维度 4 个离散条件，训练每条件独立 2048 个目标；测试每条件独立 1024 个目标。分布参数和两套数据种子先固定；同一条件明确包含多个合理目标，不是一个条件只配一个答案。固定 one-hot 条件编码，没有额外可训练主干。两层 MLP 宽度按输出维数调整，使参数量约 1.2 万。

EAR 的严格适当能量评分只约束总体目标最优解，不保证小 MLP、有限训练和随机优化能到达。连续 MLP 从连通噪声映射到分离模式时可以形成低密度连接，本实验保留了这种填充和漏模。

## 数学、实现与检查

GMM 先在同一分量内组合维度，再对分量做 logsumexp；对角与全协方差实现均和 torch.distributions 对照。全协方差下三角 L 的对角使用 softplus+0.03，Sigma=LLᵀ；不用显式逆或行列式。共享分量和逐坐标混合的数值反例见 checks.json。
EAR 官方公式采用 ||x−y||^alpha，0<alpha<2；本轮 alpha=1，两个独立噪声样本共享 condition 与 target，最小化两项到目标距离减样本间距离，温度固定1。没有运行完整 EAR，也没有实现官方大 AdaLN 网络。
平方距离能量目标：本轮未除以2的 ED₂=2||E X−E Y||²，仅识别均值。对真实 ±1、塌缩0、错误方差±2 的精确数值例子，平方版本均为0，alpha=1分别为0、1、1。这不等同于“所有平方误差都不能用于重建”。详见 SOURCES.md，也注明了原文归一化常数的差异。
公式/API、独立样本、梯度有限、采样 generator 可重现、块距离与 dense 参照均通过；仓库 tests/minimal_cpu.py 也在两个训练工作流通过。

## 失败与不确定性

程序/数值失败：0。生成分布失败另记：首轮有 71 个条件、延长轮有 67 个条件触发“覆盖率不足1或有效比例低于90%”的描述性审计标记。90%只是报告阈值，不是事后更改选型规则。全部明细保存在 RESULT.json，不用空的程序异常列表暗示没有模式失真。
两次 seed、Gaussian-mixture 真分布、固定4条件和最多8维不足以验证通用生成能力。本轮没有自回归反馈，也无法确定历史 P1/P2 自由生成失败具体由哪项机制导致。

## 唯一候选的下一轮与仍缺证据

只把 **小型全协方差 GMM** 带入下一轮真实冻结视觉特征的小实验。先测真实条件下多解、分量内相关与尾部偏差，再观察固定解码器的图像和小目标细节；不要直接铺开大模型训练。选择分数和全部对照都保留，其他头仍是本轮对照，不另推荐第二个候选。
尚缺：真实特征的维数与分布适配、分量数与参数/计算前沿、非高斯条件多解、更多 seed、等时间预算、长序列自由生成误差积累，以及解码后的细节/画质证据。合成分布成绩不能当图像画质；教师前缀 NLL 也不代表自由生成可用。
