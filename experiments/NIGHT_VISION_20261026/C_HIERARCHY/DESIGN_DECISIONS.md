# 视觉记忆原型设计决定

普通设计按任务约束自行决定；这些选择用于隔离机制，不以测试成绩证明自然语言或真实桌面能力。

| 决定 | 原因与影响 |
|---|---|
| 原图为 32×32 RGB，分成 16 个 8×8 区域，每像素一个细位置 | 全部细位置不超过 1,024，可直接计算可靠的 dense 数值参照。 |
| 区域摘要为 4×4 灰度均值，细原图另存 | 简单展示有损索引与无损存储的区别；摘要确实可能看不到目标。 |
| 四种图标同色，背景大块更亮 | 问题需要区分形状，不能仅选择最大或最亮的块。另设最亮区域对照。 |
| 查询使用四维任务 one-hot；粗 key 为 MLP 的 4 维输出 | 小型条件路由可检查。没有 tokenizer、自由文本理解或大模型。 |
| 正常训练与测试使用互补棋盘格区域，以及状态组合的不同奇偶性 | 分离空间布局与组合；单个图标形态仍来自相同程序化分布，泛化范围有限。 |
| 训练加入粗摘要完全相同的极小图标，测试单列 | 细读器能学会其区别，但路由在输入不可分辨时无法恢复位置。失败不能只归咎于细读器未训练。 |
| 细类型 MLP 只为选中区域执行，按 type 监督 | 在构造细 key 前辨别被选区域的形状；该 MLP 本身会读取该区域全部 64 个像素，其计算已记入成本。 |
| 细 K 包含类型 log 概率与归一化亮度，V 是局部坐标 one-hot | 明确、很小的 Attention 定义；输出是局部空间概率分布，后接微型二分类头。不是通用视觉特征。 |
| 粗 token 只用于路由，不进入最终细 Attention | 避免给选中区域重复加入粗、细位置。本实现用同一次 softmax 覆盖所有选中细位置。 |
| 区域先 unique 再 gather，固定非重叠区域 | 不重复编码和计算同一像素。未实现任意重叠裁剪的去重。 |
| 不缓存跨问题的细 KV，也不跨层共享 | 避免把别名缓存与少算 Attention 混淆；这里只演示按需生成。粗摘要和 key 每次问题重算，额外时间如实保留。 |
| 常规学习路由、均匀、随机、oracle 同预算，另加最亮基线 | 区分学习效果、覆盖率上限和背景捷径。oracle 仅评测时读取真值。 |
| 1920×1080 用 NASA 卫星图像复合图裁取，不插值 | 只验证真实图片的存储、分块及理论账本，不声称高分辨率语义识别。 |
| 原代码与已有实验不改动，发布到既有公开研究仓库独立分支 | 单独交接，可直接下载复查；不修改 B 或既有模型，也不合并到 main。 |

后续可以研究摘要不确定性触发扩大预算、可学习多尺度索引和真实图标布局。当前没有实现这些补救，不能用未来方案抵消已记录漏检。
