# Inverse-ViT Lab

这是关于条件像素映射与自回归像素生成的三阶段开放研究记录。仓库提供代码和实验结论供审阅与协作，也如实保留了失败结果。

## 实验结果概览

| 阶段 | 研究问题 | 观察结果 | 结论 |
|---|---|---|---|
| P0 | ViT 能否把条件映射为像素？ | 在所测合成任务上学会了条件映射；后续坐标留出实验未达到全部几何门槛。 | 仅限该任务的成功；泛化未验证 |
| P1 | 因果 ViT 能否自由生成 CIFAR-10 像素？ | 固定的 80 张自由生成图主要是噪声和色块，没有可靠可辨认的类别对象，尽管验证似然有所改善。 | 自由生成失败 |
| P2 | 预训练语言主干能否增加视觉生成并保持文字能力？ | 固定的 80 张自由生成图没有可靠对象；固定文字任务评测出现退化。 | 视觉目标失败；观察到文字能力退化 |

详见[P0](results/P0.md)、[P1](results/P1.md)、[P2](results/P2.md)阶段报告及[三阶段方法差异](docs/METHODS.md)。本项目不宣称 SOTA、通用生图成功或架构已验证。

## 仓库内容

- `p0/`、`p1/`、`p2_qwen/`：必要的模型、训练、数据准备、采样与评估代码。
- `configs/`：使用相对路径的示例配置。运行前请检查并修改硬件、数据和输出路径。
- `tests/minimal_cpu.py`：无需下载的 CPU 最小检查，覆盖三个模型路径及 P2 概率头。
- `results/`：脱敏汇总报告和完整的 P0 合成坐标对照图册。
- `docs/`：方法、复现、推理、许可证与协作说明。

基于 CIFAR-10 训练得到的 P1/P2 图册暂未纳入公开仓库，因为这些图像的公开发布权利尚未确认。仓库不包含 CIFAR-10 原始图像。

## 快速 CPU 检查

安装 `requirements-minimal.txt` 所列依赖后运行：

```sh
python tests/minimal_cpu.py
```

检查会实例化小型随机模型，并验证张量形状、有限输出、patch 往返变换和 P2 连续概率计算。它不会下载数据或模型，不会训练，也不能证明研究结果。PyTorch 安装可能需要较多磁盘空间。

## 复现实验

请先阅读[复现与独立推理说明](docs/REPRODUCE.md)。P0 合成数据可在本地生成。P1 需要自行准备 CIFAR-10 官方数据包；P2 还需要 WikiText-2、兼容的 Qwen3.5-0.8B 权重和合适的计算资源。最小 CPU 检查不会下载任何内容。不要把凭据写入配置文件。

当前公开的 P2 训练与恢复代码存在只读审计发现的控制流问题。在相关问题经过审查和修复前，请勿用它进行长时间训练或故障恢复，详见[P2 报告](results/P2.md)。

## 参与协作

重要实验开始前请先开 issue，说明假设、固定数据划分、计算预算、停止规则和报告指标。请使用主题分支，并向 `main` 提交 pull request；修改代码时应附带小型 CPU 检查。issue 和提交中不要放入凭据、个人信息、私有路径、模型权重、优化器状态、原始数据集或日志。请阅读[贡献指南](CONTRIBUTING.md)。
