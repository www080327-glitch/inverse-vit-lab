# Fixed result figures

P0 figures show the complete E0/E1 two-page synthetic condition comparisons and the complete E3 train-to-continuation comparison for all 16 held-out circle positions, for each of the three fixed seeds.

The P1 and P2 80-image CIFAR-10 output atlases are withheld from this public snapshot. The official CIFAR-10 page requests citation but does not specify an explicit dataset license. The image atlases are not raw dataset files, but they are outputs of models trained on that dataset; their redistribution status has not been established. Reports preserve the aggregate failure findings. The complete fixed atlases remain available in the originating local experiment and can be reviewed separately if publication rights are clarified.
