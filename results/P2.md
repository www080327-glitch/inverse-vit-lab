# P2: 语言模型主干与连续视觉接口

P2 在 Qwen3.5-0.8B 语言主干上接入连续 RGB patch 输出头，使用 tanh 有界像素分布和 4:1 图像/文本训练步安排。实现保留真实 Qwen 混合层结构。完整训练在固定配置下完成；固定评测中的文本指令能力退化。

自由生成固定图册为 10 类×8 seed 共 80 张，没有可靠可辨认对象。冻结分类器对最终图片判对 12/80（15%）仅是辅助信号，不是画质或人类准确率。WikiText 验证交叉熵由 3.890799 降到 3.625829，不能据此推断问答、翻译、代码和指令能力保持。

后续只读 CPU 审计还发现 checkpoint 权重/优化器状态配对、梯度累积中断后的数据游标，以及 epoch 上限控制方面的缺陷；这些问题没有在本公开包中修复。**不要依赖当前 P2 训练脚本做故障恢复或长跑，先由协作者审查并修复。** 概率头的 CPU 合成测试与模型无关；真实权重、数据、云执行记录均未发布。
